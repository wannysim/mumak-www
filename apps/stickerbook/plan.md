# Stickerbook — 사진 전시 컨셉

최초 기록: 2026-10-27. 현재 상태: 2026-10-29 사용자 요청으로 기존 디자인·화면·인터랙션 구현을 초기화했다. 아래는 다음 디자인에서도 이어갈 컨셉이며 **현재 구현된 기능 목록이 아니다**. 앱의 실행·검증 기반은 [implementation.md](./implementation.md), 재개 순서는 [NEXT.md](./NEXT.md)를 따른다.

## 핵심 경험

책상 위에 놓인 스티커북을 펼쳐 페이지를 넘기며 사진을 감상한다. 사진과 책 주인의 fursona 스티커, 만지면 반응하는 책상 소품으로 누군가의 책상과 취향을 구경하는 경험을 만든다.

독립 사진 전시 앱이다. 기존 Blog 사진전 홈 개편이나 Figma 작업의 재개, 공통 디자인 시스템 학습 단계의 완료를 뜻하지 않는다.

## 유지할 컨셉

- **책과 페이지:** 펼치면 좌우 두 페이지가 보인다. 오른쪽 장을 넘겼을 때 그 뒷면은 다음 펼침의 왼쪽 페이지가 된다. 예를 들어 02쪽 뒷면은 03쪽이며 아래에서 04쪽이 드러난다.
- **사진:** 폴라로이드 같은 프레임을 스카치 테이프로 붙인 설정. 하단 여백에는 장소 메모 대신 해당 이미지의 EXIF를 표시한다. 정보가 없으면 만들어내지 않는다.
- **스티커:** 사용자의 fursona 이미지, 흰 재단 테두리와 약간 비닐 같은 질감·광택. 페이지마다 작은 스티커 2–3개를 자연스럽게 다른 위치·각도로 붙인다. 렌더링마다 무작위로 움직이지 않는다.
- **떼는 감각:** 조심스럽게 떼면 자국 없이, 세게 확 떼면 흔적이 남는 경험. 입력 속도·각도·거리의 해석, 자국 표현과 저장 범위는 다음 구현에서 정한다.
- **책상 소품:** 하스스톤 게임판 모서리 오브젝트처럼 발견하는 상호작용. 참고작의 자산·모양을 복제하지 않으며 소품 종류와 반응은 다시 정한다.
- **화면 대응:** 휴대폰의 가로·세로, 태블릿, Flip/Fold/Duo 등 화면 특성을 고려한다. 특정 기기 지원은 실제 검증 범위를 구분해 기록한다.

## 이전에 밝힌 시각적 선호

이전 디자인 구현은 폐기했다. 아래는 사용자 선호 기록이며 새 디자인의 구체적인 배치·서체·치수·색상값을 확정한 것은 아니다.

- 미니멀하고 깔끔하게, 별도 헤더 없이 책상과 책이 중심.
- 흰색을 넓게 쓰고 주황·크림슨 레드는 작은 포인트. 처음 언급한 6:3:1을 화면 면적에 강제하지 않는다.
- 테이프는 투명하고 깔끔하게, 위치와 각도는 다양하게. 사진 자체의 색은 제한하지 않는다.
- 기존 JPG 6개는 유지한다. 실제 사용자 사진·fursona·EXIF 파이프라인은 아직 연결하지 않았다.

## 다음 설계에서 다시 정할 것

책상·책의 화면 구성과 비율, 재료감·서체·그림자, 사진을 충분히 감상할 크기, 스티커·테이프 배치, 넘김 렌더러와 제스처, 소품·소리·상태 저장, EXIF 항목과 추출 방식은 새 디자인에 맞춰 결정한다.

페이지 넘김은 사용자가 잡은 위치를 따르는 느낌이 중요하다. 누르는 순간 레이아웃이나 글자 크기·선명도가 바뀌지 않아야 한다. 키보드·터치·동작 줄이기와 충분한 조작 영역도 설계에 포함한다. 이전 구현의 물리 수치와 기하학 방식을 그대로 재사용해야 한다는 뜻은 아니다.
