# apps/stickerbook — AGENTS.md

인터랙티브 개인 홈페이지(닫힌 3D 책 → 펼쳐서 탐색) 앱 전용 규칙. 공통 규칙은 루트 `AGENTS.md` 참조. 이 파일은 경계만 요약하고, 내용의 정본은 아래 문서다.

- 작업 전에 [NEXT.md](./NEXT.md)부터 읽는다. 컨셉은 [plan.md](./plan.md), 결정 대기 목록은 [open-decisions.md](./open-decisions.md), 기술 조사와 스파이크 계획은 [tech-research.md](./tech-research.md), 스파이크 측정·운영·결과는 [spikes.md](./spikes.md).
- 디자인(시각)·제품 결정은 사용자가 먼저 판단한다. 에이전트는 선택지·근거·측정을 내고, 배치·서체·치수·색·모션 수치를 확정하지 않는다. open-decisions.md에서 사용자 결정으로 분류된 항목을 임의로 채우지 않는다.
- NEXT.md의 단계 순서를 따른다. 닫힌 책·펼친 책 정지 화면에 대한 사용자 판단 전에는 스파이크나 본 구현을 시작하지 않는다. 사용자가 디자인과 무관한 선행 작업을 허용하면 그 범위만 한다.
- 뺀 항목(책상 배경·책상 소품·떼기 자국, 폴라로이드·테이프·EXIF)을 다시 넣지 않는다. 초기화 전 커밋 `243b0f7`의 코드는 참고만 하고 자동 복구하지 않는다.
- 핵심 동작은 모든 대상 환경에서 같은 규칙·렌더 경로·글자 모양이어야 한다(tech-research.md 0장). 특정 브라우저 전용 경로로 경험을 가르지 않는다. WebGL2 컨텍스트 생성 실패 대체 경로와 최대 텍스처 크기 예외는 tech-research.md 1장·2장이 정한 명시적 예외다.
- ryOS(AGPL-3.0), turn.js, wawa-sensei book slider 코드는 쓰지 않는다. CC-BY-NC 자료는 원리만 참고하고, MIT 코드를 가져오면 고지한다(tech-research.md 8장).
- 실기기에서 확인하지 않은 환경을 지원한다고 쓰지 않는다. 결과는 확인한 기기·브라우저·버전으로 기록한다.
- 검증 명령은 [README.md](./README.md). E2E는 포트 3009에서 빌드 결과로 돌며 dev 서버를 재사용하지 않는다.
