# Stickerbook 시각 디자인

2026-10-27. 첫 프로토타입의 나무·펠트·크림색 종이·세리프 제목은 사용자 피드백으로 폐기했다. 사진 자체의 다양한 색을 받아들이는 흰 책상과 책이 중심이다. 디자인 확정이 아닌 실제 화면 비교용 수정안이다.

## 색·서체·구성

- 바탕/페이지 `#ffffff`, 표지 주황 `#f47732`, 포인트 크림슨 `#be123c`.
- 본문·조작 `#252525`, 보조 정보 `#737373`. 주황은 작은 글자의 색으로 사용하지 않는다.
- 로컬 Pretendard 단일 서체. EXIF와 페이지 번호 외의 장식 타이포그래피는 제거한다.
- 헤더 없는 흰 책상 → 중앙 책 → 하단 페이지 이동/보조 조작. 초기 상태에는 상태 메시지를 비워두고 조작 후에만 결과를 알린다.
- 사용자가 비중을 확정했다: 흰색을 넓게 두고 주황·크림슨은 작은 포인트로 사용한다. 6:3:1을 실제 화면 면적에 강제하지 않는다. 사진의 고유색은 팔레트 제한 대상이 아니다.

## 배치와 재료

- 일반 페이지마다 작은 임시 여우 스티커 2–3개. 실제 fursona 자산은 아직 미연결이다.
- 스티커별 크기·위치·각도와 테이프 1–2개의 각도를 페이지마다 다르게 지정한다. 렌더링마다 난수를 뽑지 않아 회전·넘김·왕복 시 배치가 유지된다.
- 반투명 무채색 테이프와 얇은 테두리, 약한 접촉 그림자. 누런 테이프와 종이 노이즈는 제거한다.
- 작은 스티커의 시각 크기와 최소 44px 조작 영역은 분리한다. 스티커 상태는 각 스티커 ID로 보관한다.
- 정지와 넘김에 동일한 HTML/CSS와 배치 데이터를 쓴다. 이전 WebGL 텍스처 경로는 [motion.md](./motion.md)의 후속 수정으로 제거했다. 작은 tabletop 모드는 기존대로 장식을 숨기고 사진과 즉시 이동을 우선한다.
- 넓은 화면의 소품은 흰 컵·카메라와 크림슨 연필로 단순화한다. 좁은 화면과 분할 화면에서는 숨긴다.
- JPG 6개는 변경하지 않는다. 수정 전후 해시를 비교해 바이트 동일성을 확인했다.

## 비교할 항목

책이 충분히 주인공인지, 흰 여백과 포인트 색의 비중이 취향에 맞는지, 작은 스티커와 투명 테이프가 사진을 방해하지 않으면서 발견되는지 확인한다. 사진 콘텐츠의 색과 EXIF 정책은 이번 시각 변경과 별개다.

## 수정안 검증

아래는 시각 수정 당시 기록이다. 이후 페이지 넘김 개선과 최신 검증은 [motion.md](./motion.md)를 따른다.

- 타입·lint·format·단위 48개·프로덕션 빌드 통과.
- Chromium·Firefox·WebKit E2E 21 passed / 6 skipped. skip은 Chromium 전용 CDP·WebGL 검사다.
- 페이지별 2–3개 스티커, 320px 화면의 44px 조작 영역, 사진 클릭과 스티커 클릭의 분리, 개별 상태·전체 되돌리기 회귀를 추가했다.
- verifier가 발견한 compact 여백 pointer-down의 즉시 넘김을 차단했다. 수정 후 단위 검사와 실제 CDP 분할 화면 E2E를 재실행해 통과했다.
- 데스크톱·모바일·실제 WebGL 넘김을 브라우저 스크린샷으로 확인했다. JPG 6개는 수정 전후 해시가 같다.
- 실제 폴더블 하드웨어의 사용 감각과 시각 선호는 아직 사용자 확인 전이다.
