이 노트는 그날그날 내가 던진 링크들을 모아 정리하는 *일일 읽을거리 아카이브*다.

## 운영 방식

- 하루 1개 파일로 기록한다.
- Geek News, Medium, Twitter/X, 아카이브 링크 등 출처가 섞여도 한데 모은다.
- 링크가 오면 다음 순서로 정리한다.
  - 제목
  - 출처
  - URL
  - 1줄 요약
  - 핵심 포인트
  - 왜 중요한지
  - 후속 메모

## 입력 규칙

- 링크를 여러 개 보내도 된다.
- 가능하면 링크 옆에 한 줄 코멘트를 붙인다.
  - 예: `이건 꼭 봐줘`
  - 예: `중복이면 합쳐줘`
- 출처가 명확하지 않으면 내가 판단해서 분류한다.

## 저장 규칙

- 상위 노트는 규칙과 가이드를 담는다.
- 일자별 파일은 실제 요약만 누적한다.
- 같은 날 여러 링크가 오면 하나의 일자 파일에 계속 추가한다.

## 파일 구조

```text
apps/blog/content/ko/garden/archives/daily-digest/
├── 2026-05-18.mdx
├── 2026-05-19.mdx
└── ...
```

## 추천 섹션

- `## Incoming Links`
- `## Summaries`
- `## Follow-ups`
- `## Related Notes`

## 분류 기준

- `geek-news`: 기술 뉴스 / 업계 소식
- `medium`: 블로그 / 에세이 / 장문 글
- `twitter`: 짧은 인사이트 / 스레드
- `research`: 논문 / 자료 / 조사 링크

## 메모

- 필요하면 나중에 `projects/`, `resources/`, `areas/` 노트와 wikilink로 연결한다.
- 같은 날 여러 링크가 오면 이 파일에 누적한다.
