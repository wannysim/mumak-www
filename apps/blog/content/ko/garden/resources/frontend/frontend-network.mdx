## 읽는 순서 제안

URL 입력부터 화면까지를 큰 지도로 먼저 읽고, HTTP 버전 → 캐싱으로 프로토콜을 깊게 판 뒤,
CORS → XSS·CSRF로 보안 모델을 묶어 읽는 흐름을 권한다.
XSS·CSRF를 읽었다면 실전 사례 둘 — script 안의 JSON(XSS의 변종)과
OAuth 콜백 보안(CSRF의 변종) — 으로 이어 읽으면 일반론이 손에 잡힌다.
