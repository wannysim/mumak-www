웹에서는 CSS transition/animation 한 줄이면 됐지만, RN에서는 좀 더 명시적으로 다뤄야 한다. 그리고 거의 항상 **JS 스레드를 안 거치고** 돌리는 게 관건이다.

> 기초는 [[react-native-basics-for-react-devs|RN 기초]]에서.

## 큰 그림 — 왜 JS 스레드를 피해야 하는가

RN 앱은 보통 두 스레드에서 돈다.

- **JS 스레드** — React 로직, API 호출, 터치 처리
- **UI 스레드 (Main)** — 실제 렌더링, 네이티브 애니메이션, 스크롤

매 프레임(16.67ms) 안에 JS 쪽에서 값을 계산해서 UI 쪽으로 넘기면 **JS 스레드가 막히는 순간 애니메이션도 끊긴다**. 그래서 가능한 한 애니메이션 로직을 UI 스레드에서 돌게 하는 게 RN 애니메이션의 모든 주제.

자세한 스레드 이야기는 [[react-native-performance-and-debugging|성능과 디버깅]] 노트.

## API 4가지 — 어느 걸 쓰나

| API                            | 출신    | 언제                                   |
| ------------------------------ | ------- | -------------------------------------- |
| `Animated`                     | 코어    | 간단한 페이드/슬라이드/스케일          |
| `LayoutAnimation`              | 코어    | 레이아웃 변화(크기/위치)를 한 번에 부드럽게 |
| `react-native-reanimated`      | 라이브러리 | 복잡한 인터랙션, 제스처 연동 (사실상 표준) |
| CSS-like (예: NativeWind 전환) | 라이브러리 | Tailwind 스타일 + 간단 트랜지션         |

실무에서는 **새 코드는 거의 Reanimated**. 코어 `Animated`는 간단한 케이스 + 옛 코드 유지보수용.

## Animated — 코어 애니메이션

가장 기본. timing/spring/decay 3가지 모션과 `Animated.Value`로 만든 값을 컴포넌트의 스타일에 바인딩.

```tsx
import { Animated, Easing } from 'react-native';
import { useEffect, useRef } from 'react';

export function FadeIn({ children }) {
  const opacity = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    Animated.timing(opacity, {
      toValue: 1,
      duration: 300,
      easing: Easing.out(Easing.ease),
      useNativeDriver: true,
    }).start();
  }, [opacity]);

  return <Animated.View style={{ opacity }}>{children}</Animated.View>;
}
```

### 모션 종류

```ts
Animated.timing(value, { toValue, duration, easing }); // 시간 기반
Animated.spring(value, { toValue, friction, tension });  // 물리 기반
Animated.decay(value, { velocity, deceleration });       // 관성
```

### 조합

```ts
Animated.sequence([a1, a2]).start(); // 순서대로
Animated.parallel([a1, a2]).start(); // 동시에
Animated.stagger(100, [a1, a2, a3]).start(); // 100ms 간격으로
```

### 값 매핑 (interpolate)

```ts
const scale = scrollY.interpolate({
  inputRange: [0, 100],
  outputRange: [1, 0.8],
  extrapolate: 'clamp',
});
```

문자열도 매핑 가능 — 색상, 단위 있는 값 모두.

```ts
const color = progress.interpolate({
  inputRange: [0, 1],
  outputRange: ['#ff0000', '#00ff00'],
});
```

### useNativeDriver: true가 핵심

`useNativeDriver: true`로 두면 애니메이션 설정이 처음에 한 번 네이티브로 넘어가고, **그 뒤로 JS 스레드를 안 거친다**. JS가 막혀도 애니메이션은 계속 돈다.

**제약**: `transform`과 `opacity`에만 적용 가능. width/height/padding 같은 레이아웃 속성은 못 한다 (Flexbox 재계산이 필요해서).

```tsx
// ✅ native driver OK
<Animated.View style={{ opacity, transform: [{ scale }, { translateX }] }} />

// ❌ native driver 불가 — width/height 등은 JS driver로 떨어짐
<Animated.View style={{ width: animatedWidth }} />
```

레이아웃이 진짜 변해야 한다면 `LayoutAnimation` 또는 Reanimated를 쓴다.

### 스크롤 연동

```tsx
const scrollY = useRef(new Animated.Value(0)).current;

<Animated.ScrollView
  onScroll={Animated.event(
    [{ nativeEvent: { contentOffset: { y: scrollY } } }],
    { useNativeDriver: true },
  )}
  scrollEventThrottle={16}
>
  ...
</Animated.ScrollView>;

// scrollY를 헤더 opacity나 패럴랙스에 연결
const headerOpacity = scrollY.interpolate({
  inputRange: [0, 100],
  outputRange: [1, 0],
  extrapolate: 'clamp',
});
```

## LayoutAnimation — 레이아웃이 변할 때

state가 바뀌면서 자연스럽게 크기/위치가 변해야 할 때. 한 줄 추가로 다음 렌더에서 일어나는 모든 레이아웃 변화에 트랜지션이 붙는다.

```tsx
import { LayoutAnimation, UIManager, Platform } from 'react-native';

if (Platform.OS === 'android') {
  UIManager.setLayoutAnimationEnabledExperimental?.(true);
}

function toggle() {
  LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut);
  setExpanded((v) => !v);
}
```

쓸 만한 케이스:

- "더보기" 펼치기
- 리스트 항목 추가/삭제
- 카드의 높이 변화

단점: **제어가 약하다**. 한 화면 안의 모든 변화에 똑같이 걸리고, 개별로 다른 모션을 주기 어렵다.

## Reanimated — 실무 표준

`react-native-reanimated`는 애니메이션 코드를 **JS 스레드가 아니라 UI 스레드에서 직접 실행**한다. 그래서 60fps 유지가 훨씬 쉽고, 제스처와 결합한 복잡한 모션이 자연스러워진다.

핵심은 `'worklet'` 함수와 `useSharedValue` / `useAnimatedStyle`.

```tsx
import Animated, {
  useSharedValue,
  useAnimatedStyle,
  withTiming,
  withSpring,
} from 'react-native-reanimated';

export function FadeIn({ children }) {
  const opacity = useSharedValue(0);

  useEffect(() => {
    opacity.value = withTiming(1, { duration: 300 });
  }, [opacity]);

  const style = useAnimatedStyle(() => ({
    opacity: opacity.value,
  }));

  return <Animated.View style={style}>{children}</Animated.View>;
}
```

### Reanimated를 쓰는 이유

- 레이아웃 속성(width/height 등)도 60fps 가능
- 제스처와의 결합이 매끄럽다 (다음 섹션)
- `useSharedValue`는 native 메모리에 직접 저장 — 매번 리렌더 안 일으킴
- 표현력이 좋다 (`withSequence`, `withRepeat`, `withDelay`, `cancelAnimation` 등)

새 RN 프로젝트라면 거의 무조건 시작부터 Reanimated를 깐다. Expo 프로젝트는 보통 이미 깔려 있음.

## Gesture Handler — 터치/제스처

`react-native-gesture-handler`는 RN의 기본 PanResponder를 대체하는 네이티브 제스처 시스템. Reanimated와 짝꿍.

```tsx
import { Gesture, GestureDetector } from 'react-native-gesture-handler';
import Animated, { useSharedValue, useAnimatedStyle } from 'react-native-reanimated';

export function Draggable() {
  const translateX = useSharedValue(0);
  const translateY = useSharedValue(0);

  const pan = Gesture.Pan().onChange((e) => {
    translateX.value += e.changeX;
    translateY.value += e.changeY;
  });

  const style = useAnimatedStyle(() => ({
    transform: [
      { translateX: translateX.value },
      { translateY: translateY.value },
    ],
  }));

  return (
    <GestureDetector gesture={pan}>
      <Animated.View style={[styles.box, style]} />
    </GestureDetector>
  );
}
```

제공되는 제스처:

- `Pan` — 드래그
- `Tap` — 탭 (싱글/더블/N번)
- `LongPress` — 길게 누르기
- `Pinch` — 두 손가락 줌
- `Rotation` — 회전
- `Fling` — 휙 던지기

여러 개 조합도 가능 (`Gesture.Race`, `Gesture.Simultaneous`, `Gesture.Exclusive`).

## 자주 부딪히는 함정

### "애니메이션이 끊긴다"

원인 우선순위:

1. `useNativeDriver: true`를 안 줬다
2. dev 빌드에서 보고 있다 ([[react-native-performance-and-debugging|성능 노트]] 참고)
3. 매 프레임 JS 쪽에서 무거운 일을 하고 있다
4. 레이아웃 속성을 native driver로 돌리려고 하고 있다 (불가능)

### "ref가 안 잡힌다"

`Animated.View`는 `Animated.createAnimatedComponent(View)`로 감싼 거라 자식 컴포넌트로 ref를 쓰려면 forwarding이 필요할 수 있다. 보통 그냥 `Animated.View`를 직접 쓰면 된다.

### "Reanimated worklet에서 console.log가 안 보인다"

Worklet 안의 `console.log`는 UI 스레드라 별도 처리. 콘솔에 안 뜨면 `runOnJS`로 JS 쪽 함수를 호출해서 로깅하거나, Reanimated의 디버깅 옵션을 켠다.

```ts
import { runOnJS } from 'react-native-reanimated';

const pan = Gesture.Pan().onChange((e) => {
  translateX.value += e.changeX;
  runOnJS(setLog)(`x=${translateX.value}`);
});
```

## 선택 가이드

- 페이드/스케일/슬라이드 같은 간단한 거 → `Animated` + `useNativeDriver: true`
- 레이아웃 자체가 변하는 토글 → `LayoutAnimation`
- 제스처가 끼거나 60fps가 중요한 거 → `Reanimated` + `Gesture Handler`
- 새 프로젝트면 처음부터 Reanimated 깔고 시작
