프론트엔드 코드의 런타임은 결국 브라우저다.
HTML 한 장이 픽셀이 되기까지, 스크립트 한 줄이 로딩을 막기까지, 데이터 한 조각이 어디에 저장되기까지 —
브라우저가 하는 일을 직접 들여다보는 노트 모음이다.

## 읽는 순서 제안

렌더링 파이프라인을 먼저 읽고 스크립트 로딩으로 넘어가면
"왜 `<script>` 위치가 중요한가"가 파이프라인 위에서 자연스럽게 이해된다.
Core Web Vitals는 앞의 두 노트를 측정 지표 관점에서 다시 묶어준다.
