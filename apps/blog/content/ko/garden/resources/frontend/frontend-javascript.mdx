"동작한다"와 "왜 그렇게 동작하는지 안다"는 다르다.
자바스크립트라는 언어가 엔진 위에서 실제로 어떻게 굴러가는지를 파고드는 노트 모음이다.

코드를 한 줄 실행할 때 콜 스택에서 무슨 일이 벌어지는지, 클로저가 메모리에 어떻게 남는지,
`this`가 왜 그때그때 다른지 같은 "왜?"에 답하는 것이 목표다.

이벤트 루프 → 클로저 → 프로토타입과 this → Promise → V8 순서로 읽으면
"실행 모델 → 메모리 모델 → 객체 모델 → 비동기 모델 → 엔진 내부" 흐름으로 자연스럽게 이어진다.
