웹 React에서 `<div>` 하나로 다 처리하던 걸 RN에서는 용도별로 다른 컴포넌트를 쓴다. "지금 쓰려는 건 어느 컴포넌트인가"를 빠르게 떠올릴 수 있는 지도.

> 기초는 [[react-native-basics-for-react-devs|RN 기초]] 노트 참고.

## 컴포넌트 4계열로 나눠 보기

RN 코어 컴포넌트는 대략 4가지 계열로 나눌 수 있다.

1. **레이아웃/표시** — View, Text, Image
2. **입력/상호작용** — TextInput, Pressable, Switch, Button
3. **리스트/스크롤** — ScrollView, FlatList, SectionList
4. **시스템/오버레이** — Modal, ActivityIndicator, Alert, StatusBar, KeyboardAvoidingView

플랫폼 전용(`SafeAreaView` 같은 iOS-only, `BackHandler` 같은 Android-only)은 별도로 다룬다.

## 레이아웃/표시

### View

웹의 `<div>`. 사각형 컨테이너. flex 컨테이너이고 기본 `flexDirection: 'column'`.

```tsx
<View style={{ flex: 1, padding: 16 }}>{children}</View>
```

### Text

모든 텍스트는 이 안에. 폰트 속성은 자식 `<Text>`에 상속된다 (View와 다른 점).

```tsx
<Text style={{ fontSize: 18, fontWeight: '600' }}>
  안녕 <Text style={{ color: 'red' }}>윤하</Text>
</Text>
```

`numberOfLines`로 줄임표 처리:

```tsx
<Text numberOfLines={2} ellipsizeMode="tail">긴 텍스트...</Text>
```

### Image

원격 이미지는 사이즈 명시 필수. 로컬은 `require`로 가져오면 자동.

```tsx
<Image source={{ uri: 'https://...' }} style={{ width: 64, height: 64 }} />
<Image source={require('./icon.png')} />
```

`resizeMode`로 채움 방식 제어: `cover` / `contain` / `stretch` / `center`.

### ImageBackground

배경 이미지 위에 자식을 얹을 때. (CSS `background-image`의 대체)

```tsx
<ImageBackground source={...} style={{ flex: 1 }}>
  <Text>위에 얹히는 내용</Text>
</ImageBackground>
```

## 입력/상호작용

### TextInput

웹의 `<input>` + `<textarea>` 통합. 자세한 패턴은 [[react-native-conventions|RN 컨벤션 노트]]의 키보드 섹션 참고.

```tsx
<TextInput
  value={text}
  onChangeText={setText}
  placeholder="이름"
  keyboardType="default" // email-address, numeric, phone-pad 등
  secureTextEntry={false} // 비밀번호일 때 true
  autoCapitalize="none"
  multiline={false}
/>
```

`onChange`가 아니라 `onChangeText`라는 점이 핵심. 이벤트 객체 대신 문자열을 바로 받는다.

### Pressable

현재 권장되는 클릭(탭) 컴포넌트. 옛날 코드의 `TouchableOpacity` / `TouchableHighlight`를 점차 대체.

```tsx
<Pressable
  onPress={handlePress}
  onLongPress={handleLongPress}
  style={({ pressed }) => [
    styles.button,
    pressed && { opacity: 0.6 },
  ]}
>
  <Text>탭</Text>
</Pressable>
```

`style`에 함수를 넣어서 `pressed` 상태에 따라 스타일 변경 가능. 웹의 `:active`에 가까운 패턴.

### Button

플랫폼 기본 스타일 그대로 쓰는 가장 간단한 버튼. **커스터마이즈 거의 안 됨**. 실서비스에서는 보통 `Pressable`로 직접 만든다.

```tsx
<Button title="저장" onPress={handleSave} color="#007AFF" />
```

### Switch

iOS/Android의 네이티브 토글.

```tsx
<Switch value={isOn} onValueChange={setIsOn} />
```

## 리스트/스크롤

선택 기준은 항목 개수와 동적성:

| 상황                            | 사용                  |
| ------------------------------- | --------------------- |
| 한 화면 안에 들어오는 정적 목록 | `View` + .map         |
| 화면 넘는 짧은 목록             | `ScrollView` + .map   |
| 길거나 동적인 목록              | `FlatList`            |
| 섹션이 있는 목록 (헤더로 묶임)  | `SectionList`         |
| 더 빠른 것이 필요할 때          | `FlashList` (Shopify) |

### ScrollView

기본 스크롤. 자식을 다 렌더링한다 (가상화 없음).

```tsx
<ScrollView
  horizontal={false}
  showsVerticalScrollIndicator={true}
  contentContainerStyle={{ padding: 16 }}
>
  {children}
</ScrollView>
```

`style` vs `contentContainerStyle` 구분이 중요:

- `style` — 스크롤 뷰 자체의 박스 (`flex: 1` 같은 거)
- `contentContainerStyle` — 안의 내용물 컨테이너 (`padding` 같은 거)

### FlatList

가상화된 리스트. 화면 밖 항목은 unmount.

```tsx
<FlatList
  data={items}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => <Card item={item} />}
  ItemSeparatorComponent={() => <Divider />}
  ListEmptyComponent={<Empty />}
  ListHeaderComponent={<Header />}
  ListFooterComponent={<Footer />}
  onEndReached={loadMore}
  onEndReachedThreshold={0.5}
  refreshing={isRefreshing}
  onRefresh={refresh}
/>
```

성능 옵션 (퍼포먼스가 안 좋을 때):

- `getItemLayout` — 항목 높이가 고정이면 사용. 측정 비용 사라짐.
- `removeClippedSubviews` — 화면 밖 항목 즉시 떼어냄
- `initialNumToRender`, `windowSize`, `maxToRenderPerBatch` — 렌더 윈도우 튜닝

### SectionList

`FlatList`와 거의 같지만 섹션 헤더가 있다.

```tsx
<SectionList
  sections={[
    { title: 'A', data: [...] },
    { title: 'B', data: [...] },
  ]}
  renderItem={({ item }) => <Row item={item} />}
  renderSectionHeader={({ section }) => <Header title={section.title} />}
  keyExtractor={(item) => item.id}
/>
```

## 시스템/오버레이

### Modal

화면 위로 떠오르는 풀스크린/슬라이드 오버레이.

```tsx
<Modal
  visible={isOpen}
  onRequestClose={close}
  animationType="slide" // fade, none
  transparent={false}
  presentationStyle="pageSheet" // iOS only
>
  <View>{children}</View>
</Modal>
```

`Modal`은 기본 OS 위에 새 윈도우를 띄우는 거라 RN의 네비게이션 스택과는 별도다. 화면 단위 모달은 보통 네비게이션 라이브러리의 modal screen을 쓴다 ([[react-native-navigation|네비게이션 노트]]).

### ActivityIndicator

로딩 스피너. 단색 동그라미가 빙빙 도는 거.

```tsx
<ActivityIndicator size="large" color="#007AFF" />
```

### Alert

OS 기본 다이얼로그.

```tsx
import { Alert } from 'react-native';

Alert.alert('삭제할까요?', '되돌릴 수 없습니다.', [
  { text: '취소', style: 'cancel' },
  { text: '삭제', style: 'destructive', onPress: handleDelete },
]);
```

**JSX가 아니라 명령형 API**라는 게 함정. 시간이 좀 지나면 디자인이 강제되므로, 커스텀 디자인이 필요하면 `Modal`이나 라이브러리.

### StatusBar

상단 상태바(시간/배터리 영역) 스타일링.

```tsx
<StatusBar barStyle="dark-content" backgroundColor="#fff" />
```

### KeyboardAvoidingView

키보드가 입력창을 가리지 않도록. 자세한 패턴은 [[react-native-conventions|컨벤션 노트]] 키보드 섹션.

## 플랫폼 전용 컴포넌트

### iOS만

- `SafeAreaView` — 내장 버전보다는 `react-native-safe-area-context` 권장
- `ActionSheetIOS` — iOS 액션 시트
- `InputAccessoryView` — 키보드 위에 붙는 액세서리 뷰

### Android만

- `BackHandler` — 하드웨어 백 버튼 처리
- `ToastAndroid` — 안드로이드 토스트
- `PermissionsAndroid` — 권한 요청 (보통은 `expo-permissions` 같은 추상화를 더 많이 씀)
- `TouchableNativeFeedback` — 머터리얼 ripple 효과
- `DrawerLayoutAndroid` — 안드로이드 드로어

플랫폼 전용 컴포넌트를 직접 쓰기보다, 양쪽 OS를 추상화한 라이브러리(react-navigation, react-native-safe-area-context 등)를 쓰는 게 보통 더 깔끔.

## 좋은 라이브러리로 확장하는 것들

코어가 약하거나 디자인이 강제돼서 거의 항상 라이브러리로 갈아끼우는 영역:

| 영역      | 코어                  | 거의 항상 쓰는 라이브러리                     |
| --------- | --------------------- | --------------------------------------------- |
| 리스트    | FlatList              | @shopify/flash-list                           |
| 애니메이션 | Animated              | react-native-reanimated                       |
| 제스처    | PanResponder          | react-native-gesture-handler                  |
| 이미지     | Image                 | expo-image (혹은 react-native-fast-image)     |
| 안전 영역 | SafeAreaView          | react-native-safe-area-context                |
| 다이얼로그 | Alert / Modal         | 디자인 시스템의 자체 Dialog 컴포넌트          |
| 폰트       | (없음)                | expo-font                                     |
| 아이콘     | (없음)                | @expo/vector-icons 또는 lucide-react-native   |

웹에서도 코어 `<input type="date">`보다 라이브러리를 쓰는 것과 비슷한 맥락.
