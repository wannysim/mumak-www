[[digital-garden-expansion-plan|디지털 가든]]에 남겨두는 앱 아이디어 메모.
이건 단순한 와인 기록 앱보다, *와인을 마시는 경험 자체를 더 펜시하게 만들어주는 인터랙티브 코치*에 가깝다.

## 한 줄 정의

사용자가 자연어로 길게 쓰지 않아도, _터치만으로 간편하게 테이스팅을 기록하고_, 기록이 쌓일수록 내 세계지도와 취향 지도가 점점 더 선명해지며, _마셔본 만큼 지도가 밝아지고 칭호가 쌓이는_ 앱.

## 핵심 컨셉

- 메인은 자유 입력이 아니다.
- 사용자는 버튼, 칩, 슬라이더, 스와이프 같은 *가벼운 터치*만 한다.
- 앱은 선택지를 점점 더 세밀하게 열어주면서, 사용자를 자연스럽게 깊은 테이스팅으로 유도한다.
- 동시에 사용자가 마신 와인의 **와이너리/산지/국가**를 지도에 누적해서 보여준다.
- 매번 마실 때마다 지도가 조금씩 밝아지고, 내 취향의 지리적 범위가 넓어지는 느낌이 핵심이다.
- 마신 기록은 **칭호**와 **밝혀지는 지도**라는 두 축의 성취감으로 보상된다.

## 지도 기반 경험

이 앱의 재미는 "무슨 와인을 마셨는가"를 넘어서, "내가 어디까지 마셔봤는가"를 시각화하는 데 있다.
젤다 야숨/왕눈에서 맵을 밝혀나가듯, *마셔본 산지를 하나씩 밝혀나가는 탐험*의 감각을 목표로 한다.

### 1) 밝혀나가는 지구본 (탐험 메타포)

- 처음엔 지구본 전체가 어둡게(미탐험) 깔려 있다.
- 와인을 마실 때마다 그 와이너리가 속한 지역이 _빛나며 밝아진다_.
- 야숨/왕눈의 맵 밝히기처럼, 한 번이라도 마신 곳은 안개가 걷히고, 많이 마실수록 더 환하게/짙게 색이 쌓인다.
- 처음 밝히는 산지는 더 강한 연출(빛 번짐, 짧은 하이라이트)로 "새로운 발견"의 쾌감을 준다.
- 우리 가든의 react-force-graph 기반 그래프 뷰에서 노드 간 관계를 인터랙티브하게 탐색하듯, 지구본도 터치/드래그로 회전·확대하며 내가 밝힌 영역을 둘러볼 수 있다.
- 빈 영역(아직 안 마신 산지)은 자연스럽게 다음 탐험 목표로 보인다.

### 2) 국가/지역 지도 (줌인)

- 지구본에서 한 국가로 줌인하면 세부 산지로 들어간다.
- 프랑스면 보르도, 부르고뉴, 론처럼 세부 산지로 나뉜다.
- 이탈리아면 피에몬테, 토스카나처럼 구역 단위로 채운다.
- 지역별로 밝기/색이 쌓이면서 "어느 산지를 많이 마셨는지" 한눈에 보인다.
- 같은 밝혀나가기 규칙을 국가 내부에도 동일하게 적용해, 줌 레벨이 달라도 일관된 탐험 감각을 유지한다.

### 3) 개인 취향 지도

- 실제 지도가 아니라도 된다.
- 내가 자주 마시는 산지/품종/스타일을 한 장의 커버리지 맵처럼 보여줄 수 있다.
- 예: 구세계 vs 신세계, 산미 중심 vs 바디 중심, 레드 vs 화이트 비중.

## 칭호 / 업적 시스템

밝혀나가는 지도가 "어디까지 가봤나"의 시각적 보상이라면, 칭호는 그 성취를 *언어화한 배지*다.
특정 지역/품종/스타일을 충분히 경험하면 칭호를 부여해서 성취욕과 수집욕을 자극한다.

### 칭호의 종류 (초안)

- **지역 마스터리**: 특정 산지를 많이 마시면 부여. 예) 부르고뉴를 일정 수 이상 마시면 "부르고뉴 왕", 보르도면 "보르도 영주".
- **국가/대륙 커버리지**: 한 국가의 주요 산지를 모두 밝히면 "프랑스 일주" 같은 칭호.
- **품종 컬렉터**: 피노 누아·네비올로 등 특정 품종을 폭넓게 마시면 부여.
- **스타일 탐험가**: 구세계/신세계, 내추럴, 스파클링 등 스타일 축을 골고루 채우면 부여.
- **희소 발견**: 마이너 산지/품종을 처음 밝히면 주어지는 일회성 칭호.

### 부여 규칙 방향

- 칭호는 **마신 횟수**와 **밝힌 범위(다양성)** 두 축을 섞어서 판정한다.
- 같은 와인만 반복해서 칭호를 따는 것보다, 다양하게 밝힐수록 유리하게 설계한다.
- 칭호에 **티어**(예: 브론즈 → 실버 → 골드)를 둬서 장기적인 동기를 준다.
- 대표 칭호 1개를 프로필에 노출하고, 나머지는 컬렉션 화면에서 모아 본다.
- 지도와 연동: 칭호 획득 순간, 해당 지역이 지도에서 강조 연출되며 잠금 해제되는 느낌을 준다.

### 열린 질문 (칭호)

- 칭호 임계값을 절대 횟수로 둘지, 상대(상위 %) 기준으로 둘지.
- 칭호 카피 톤: 진지한 소믈리에 톤 vs 가벼운 게임 톤 중 어디로?
- 칭호가 너무 흔해지면 가치가 떨어진다 — 희소성 밸런스를 어떻게 잡나.

## 지금까지 정리한 방향

- 와인 경험을 더 펜시하게 만드는 앱이다.
- 테이스팅 기록은 자연어보다 _터치_ 중심으로 빠르게 남긴다.
- 기록이 쌓일수록 세계지도, 지역 지도, 취향 지도가 점점 더 밝아진다.
- 밝혀나가는 지도와 칭호 시스템으로 탐험·수집의 성취감을 준다.
- 모바일과 웹은 따로 놀지 않고, 같은 웹앱/웹뷰 경험으로 맞춘다.
- 이 프로젝트는 UI/UX 비중이 높아서 기획/디자인 보조가 같이 필요하다.

## UX 방향

### 1단계: 감각의 큰 덩어리

처음엔 아주 단순하게 시작한다.

- 가벼움 / 중간 / 묵직함
- 산뜻함 / 균형 / 진함
- 과일 / 꽃 / 허브 / 나무 / 스파이스

### 2단계: 선택에 따라 더 깊게

예를 들어 사용자가 *과일*을 고르면 다음엔:

- 시트러스
- 사과 / 배
- 베리
- 잘 익은 과일

사용자가 *산미 높음*을 고르면 다음엔:

- 날카로운 산미
- 생동감 있는 산미
- 상큼한 산미

이런 식으로, *처음엔 쉬운 말*로 시작해서 *나중엔 더 정교한 표현*으로 들어간다.

### 3단계: 앱이 정리

마지막엔 사용자가 누른 선택들을 바탕으로 앱이:

- 테이스팅 노트 요약
- 비슷한 와인 추천
- 내 취향 프로필 반영
- 해당 와인의 와이너리/산지 밝히기
- 칭호 진행도 갱신 (획득 시 축하 연출)

까지 해준다.

## 제품 스펙 초안

### 핵심 사용자 흐름

1. 와인을 기록한다.
2. 앱이 와인 메타데이터를 가져오거나 수동 입력을 받는다.
3. 테이스팅 질문이 1개씩 나온다.
4. 사용자는 터치로 답한다.
5. 테이스팅 노트가 저장된다.
6. 지도 3종이 함께 밝아지고, 칭호 진행도가 갱신된다.

### 필수 데이터 필드

- 와인명
- 생산자 / 와이너리
- 국가
- 지역 / 서브리전
- 품종
- 빈티지
- 테이스팅 태그
- 내 평점
- 마신 날짜

### 첫 버전 MVP

- 와인 추가
- 와이너리 위치 자동 매핑
- 세계 지도 / 지역 지도 / 취향 지도 3종 표시 (밝혀나가기 연출 포함)
- 터치 기반 테이스팅 질문 플로우
- 기록 리스트
- 개인 통계
- 기본 칭호 1~2종 (지역 마스터리)으로 시스템 검증

### 나중에 붙일 수 있는 것

- 칭호 풀 확장 + 티어/컬렉션 화면
- 블라인드 테이스팅 모드
- 라벨 사진 OCR
- 친구와 비교하는 지도 / 칭호 랭킹
- 여행 기록과 와인 기록 연결
- 맛 프로필 추천

## 화면 메모

- 한 화면에 질문 하나
- 큰 버튼 3–6개
- 상단에는 지금까지의 선택이 쌓임
- 하단에는 다음 질문이 더 정교해짐
- 지도는 별도 탭 또는 하단 영역에서 항상 보이게 유지
- 칭호 획득은 기록 저장 직후 가벼운 토스트/모달로 알리고, 컬렉션 화면에서 모아 본다

## 웹앱/모바일 구현 방향

- **하나의 웹앱**으로 만들고 모바일과 웹이 같은 동작을 하게 한다.
- 모바일은 네이티브 앱이 아니라 **웹뷰 / PWA / 반응형 웹**으로 맞춘다.
- 지도 인터랙션은 터치와 클릭이 모두 동일하게 동작해야 한다.
- 화면 크기에 따라:
  - 모바일: 질문 플로우 우선, 지도는 접힘/탭 전환
  - 웹: 지도와 폼을 나란히 보여줌
- 기술적으로는 동일한 상태 머신과 동일한 데이터 모델을 쓰는 게 좋다.
- 밝혀나가기 연출은 WebGL/Canvas 기반(지구본은 globe 라이브러리, 가든 그래프처럼 인터랙티브 캔버스)이 후보다.

## 아직 열린 질문

- 세 개의 지도를 어떤 축으로 나눌까? 국가 / 지역 / 취향이면 충분할까?
- 와이너리 좌표는 자동 데이터셋으로 채울까, 수동 보정할까?
- 지도 밝히기는 "마신 횟수" 기준일까, "새로 발견한 산지" 기준일까? (칭호와 축을 어떻게 분담할지 포함)
- 초보자용 표현과 전문가용 표현을 어디서 갈라야 할까?
- 블라인드 테이스팅 모드를 넣을까?
- 개인 취향 분석을 어느 시점부터 보여줄까?
- 와인 라벨/사진 입력은 보조 기능으로 둘까, 초반 핵심으로 둘까?
- 칭호 임계값/희소성/카피 톤을 어떻게 잡을까? (위 칭호 섹션의 열린 질문)
