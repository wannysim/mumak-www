[[digital-garden-expansion-plan|디지털 가든]]에 남겨두는 앱 아이디어 메모.
이건 단순한 와인 기록 앱보다, *테이스팅을 배우게 만드는 인터랙티브 코치*에 가깝다.

## 한 줄 정의

사용자가 자연어로 길게 쓰지 않아도, _터치만으로 감각을 좁혀가며_ 와인 테이스팅 노트를 만드는 앱.

## 핵심 전제

- 메인은 자유 입력이 아니다.
- 사용자는 버튼, 칩, 슬라이더, 스와이프 같은 *가벼운 터치*만 한다.
- 앱이 선택지를 점점 더 세밀하게 열어주면서, 사용자를 자연스럽게 깊은 테이스팅으로 유도한다.

## UX 방향

### 1단계: 감각의 큰 덩어리

처음엔 아주 단순하게 시작한다.

- 가벼움 / 중간 / 묵직함
- 산뜻함 / 균형 / 진함
- 과일 / 꽃 / 허브 / 나무 / 스파이스

### 2단계: 선택에 따라 더 깊게

예를 들어 사용자가 *과일*을 고르면 다음엔:

- 시트러스
- 사과 / 배
- 베리
- 잘 익은 과일

사용자가 *산미 높음*을 고르면 다음엔:

- 날카로운 산미
- 생동감 있는 산미
- 상큼한 산미

이런 식으로, *처음엔 쉬운 말*로 시작해서 *나중엔 더 정교한 표현*으로 들어간다.

### 3단계: 앱이 정리

마지막엔 사용자가 누른 선택들을 바탕으로 앱이:

- 테이스팅 노트 요약
- 비슷한 와인 추천
- 내 취향 프로필 반영

까지 해준다.

## 이 아이디어의 포인트

- 기록보다 *학습 경험*에 가깝다.
- 초보도 부담 없이 시작할 수 있다.
- 테이스팅 용어를 외우는 대신, _느낌을 고르다 보면 용어를 배우게 된다._

## 화면 메모

- 한 화면에 질문 하나
- 큰 버튼 3–6개
- 상단에는 지금까지의 선택이 쌓임
- 하단에는 다음 질문이 더 정교해짐

## 아직 열린 질문

- 초보자용 표현과 전문가용 표현을 어디서 갈라야 할까?
- 블라인드 테이스팅 모드를 넣을까?
- 개인 취향 분석을 어느 시점부터 보여줄까?
- 와인 라벨/사진 입력은 보조 기능으로 둘까, 초반 핵심으로 둘까?
