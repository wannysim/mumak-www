## Workflow

- Keep one file per day.
- Collect links from Geek News, Medium, Twitter/X, archive pages, and more in one place.
- When a link arrives, summarize it with:
  - title
  - source
  - URL
  - one-line summary
  - key takeaways
  - why it matters
  - follow-up notes

## Input rules

- You can send multiple links at once.
- If possible, add a short note next to each link.
  - Example: `please prioritize this`
  - Example: `merge if duplicate`
- If the source is unclear, I will classify it myself.

## Storage rules

- The top-level note holds the rules and guide.
- Daily files hold the actual summaries.
- If multiple links arrive on the same day, append them to the same daily file.
