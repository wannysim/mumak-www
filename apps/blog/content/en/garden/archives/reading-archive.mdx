This note is the parent node for the day-by-day links I collect and organize.

## Archive rules

- This note acts as the parent note.
- Daily notes are connected to this note via `parent`.
- It can collect mixed sources like Geek News, Medium, Twitter/X, and archive links.
- Record one file per day.
- If multiple links arrive on the same day, keep appending them into the same daily file.

## Input rules

- Multiple links are fine.
- If possible, add a short note next to the link.
  - e.g. `please pay attention to this`
  - e.g. `merge if duplicated`
- If the source is unclear, I will classify it myself.

## Storage rules

- The parent note stores rules and guidance.
- Daily files store only the actual summaries.
- If needed, connect them later to `projects/`, `resources/`, or `areas/` notes via wikilinks.

## File structure

```text
apps/blog/content/en/garden/archives/reading-archive/
├── 2026-05-18.mdx
├── 2026-05-19.mdx
└── ...
```
