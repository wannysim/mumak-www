## Suggested Reading Order

Start with "From URL to Pixels" as the big-picture map, then dig deep into the protocol with HTTP versions followed by caching, and finally tie the security model together by reading CORS followed by XSS and CSRF.
Once you've read XSS and CSRF, follow up with the two field cases — JSON inside a script tag (a variant
of XSS) and OAuth callback security (a variant of CSRF) — to make the general principles concrete.
To grasp authentication from the ground up, first establish the essence of the ticket with sessions vs tokens,
then build on it with the Access + Refresh token pattern for the real-world implementation (the memory + httpOnly combo).
For OAuth/OIDC, read state first to understand callback binding, then compare Authorization Code and ID Token, then read nonce to understand how the ID Token itself is bound to the request.
For mobile social login, separate the provider idToken's job from our service refreshToken's job.
If production troubleshooting interests you, read keep-alive timeout ordering to establish the connection-reuse rules behind a load balancer,
then TCP retransmission timeout to develop the instinct that an error's duration is a fingerprint.
