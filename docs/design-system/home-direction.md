# 홈 방향과 취향 기록

2026-09-18 대화 기준. 본인이 말한 목적과 의사결정은 유지한다. 다만 시각 디자인은 더 고민하기로 했으며, 지금까지 만든 홈 시안과 관련 코드 변경은 모두 원복했다. 이 문서는 다음 디자인을 고민할 때 참고할 기록이며 현재 화면의 구현 계약이 아니다.

## 어떤 첫인상을 원하는가

- “우와, 이런 걸 이렇게 표현할 수 있다니!”라는 놀라움과 재미.
- 심완이라는 사람이 어떤 사람인지 흥미를 갖고 구경하는 홈.
- 글을 보도록 유도하는 데 치우친 구성에서 벗어나고 싶다.
- 취향과 활동을 구경하다 더 알고 싶은 사람이 자발적으로 글·디지털 가든·다른 작업을 탐색하길 바란다.
- 깔끔하게 완성하지 못하면 “그래서 누구인데, 들은 음악과 와인을 자랑하는 건가?”로 느껴질 수 있다는 우려가 있다. 이는 본인의 예상이며 실제 방문자에게 확인한 반응은 아니다.

여행 계획과 현재 위치도 처음에 이야기했지만, 소재가 많다고 판단해 둘 다 제외했다.

## 사진 취향

풍경, 거리의 순간, 일상, 일상 사물 같은 것을 많이 찍는다. 인물은 초상권을 고려해 함부로 촬영하거나 게시하지 않는다.

여러 장을 동시에 나열하기보다 한 장이 크게 눈길을 끌고, 더 보고 싶은 사람이 사진 전용 전시로 들어가는 흐름을 선호했다. 실제 작품의 분위기, 색감, 크롭과 전시 구성은 아직 정하지 않았다.

## 문구와 화면에 대한 선호

- 자기소개는 장황하지 않게. 대화에서 선택한 문구는 **“개발하고 사진 찍는 심완입니다.”**다. 문구의 코드 적용도 이번에 원복했다.
- 사진 아래 “풍경, 거리, 일상의 장면”, “사진전 준비 중”은 필요 없는 요소로 느꼈다.
- 헤더에 글·가든 진입이 있다면 콘텐츠 하단의 “글 읽기”, “가든 둘러보기”는 중복으로 느꼈다.
- PC와 모바일 모두 기기에 맞게 가능한 한 한 화면에 들어오는 구성을 선호한다. PC에서 말했던 스크롤 불편은 **세로 스크롤**이었다.
- 음악·와인·AI 영역 아래에 불필요하게 남는 공간이 신경 쓰였다.
- 홈은 자신에 대한 흥미에 집중해야 하는데, 헤더·푸터가 콘텐츠를 중앙 배치하고 화면에 맞추는 데 방해가 된다고 느꼈다.
- 홈 전용 레이아웃 분리도 논의하고 시도했으나 해당 구현 역시 원복했다. 구체적인 메뉴 위치·헤더·푸터 처리와 중앙 배치 방식은 다음 디자인에서 재검토한다.

## 계속 유지할 기준과 남은 고민

키보드 조작과 포커스 식별, 하나의 브랜드 기준색과 용도·테마별 변형, 글의 성숙도를 나타내는 성장 단계, 모바일 본문의 줄 밀도에 대한 판단은 [제품 원칙](./principles.md)에 유지한다.

다음 디자인에서는 사진이 사람에 대한 호기심으로 이어지는지, 나머지 소재와 소개가 어떤 관계로 읽히는지, 탐색 요소가 어느 정도 보여야 하는지를 더 고민한다. 현재 시안의 열 수·높이·간격·위젯 배치를 확정안으로 이어받지 않는다. 대표 사진 선정, 전시 표현, 데이터 연동도 미정이다.
